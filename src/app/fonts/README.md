# Fonts

Self-hosted so the build never needs network access to Google Fonts.
All three are SIL Open Font License 1.1 (see OFL.txt), from Fontsource 5.3.0.

- `bricolage-grotesque-variable.woff2`: display / headings (Bricolage Grotesque, latin, wght 200–800)
- `geist-variable.woff2`: body (Geist, latin, wght 100–900)
- `geist-mono-variable.woff2`: small technical labels only (Geist Mono)

Temporary choices until Acorn's brand kit arrives. Swap the files and the
`localFont` calls in `src/app/layout.tsx`.
